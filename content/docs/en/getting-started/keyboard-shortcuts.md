These are the shortcuts the product has today. Nothing else is bound: there is no single-key shortcut mode,
no quick-create key, and no **/** key for the palette.

## Everywhere

| Keys | What happens |
| --- | --- |
| ⌘K / Ctrl+K | Open or close the [command palette](getting-started/find-your-way). |
| Enter | Submit a search field you are typing in: the header search, the search page, a list filter. |
| Escape | Close a dialog, and close the sidebar drawer on a small screen. |

## On a record

| Keys | What happens |
| --- | --- |
| ⌘Enter / Ctrl+Enter | Save the create or edit form. |
| Enter or Space | Start editing a list cell when the cell is focused. |
| Enter | Commit an inline edit. |

The same **⌘Enter** combination posts a note to a record's stream and sends a reply in a case conversation.
Composer fields hint it in their own text — look for "⌘/Ctrl + Enter to post".

## In the chat workspace

| Keys | What happens |
| --- | --- |
| Enter | Send the message. |
| Shift+Enter | Add a line without sending. |
| Escape | Stop an answer that is still being produced. |

## With the sidebar

Focus the collapse button and press **Enter** or **Space** to fold the sidebar to icons.

> [!NOTE]
> Everything in this product is reachable without a shortcut. If a key combination is not in this table, it
> is not bound — a browser or operating-system key still does whatever your browser decides.
