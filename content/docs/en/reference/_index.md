## What is in this section

Five pages, each built to be looked up rather than read through:

- [Glossary](glossary) — what this product calls a record, a field, a queue, a document.
- [Frequently asked questions](faq) — short answers, each pointing at the page that covers it.
- [Troubleshooting](troubleshooting) — the symptom and the message you saw, then the cause and the fix.
- [Who can see what](permissions-matrix) — the actions, the levels, and why a button is missing.
- [What's new](release-notes) — where the release notes live and how to read one.

## How to use it

Every statement here describes the build you are signed into, including the things it does not have.
Where a term and a screen disagree, the screen wins: this handbook tells you what a control does, and
the server decides whether you may use it.
