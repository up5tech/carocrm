## EmailTemplate visual designer (GrapesJS)

User request (vi): "EmailTemplate khi sửa thêm page sửa chuyên nghiệp bằng cách dùng grapesjs để tạo email design visual".

- Added `grapesjs@0.23.8` to `apps/web` (lockfile + package.json; installed manually — see MEMORY.md broker note).
- New `apps/web/src/components/email/`:
  - `EmailVisualEditor.tsx` — React wrapper (forwardRef handle `insertToken`), `storageManager:false`,
    `devicePreviewMode:true`, custom email-only style sectors, devices Desktop 640 / Mobile 375,
    `open-blocks` on init, per-block `onClick` append, debounced export (400ms).
  - `emailBlocks.ts` — 9 table-based blocks (1/2/3-col sections, text, heading, button, image,
    divider, spacer), inline-SVG icons, placeholder image is a data URI.
  - `inlineEmailCss.ts` — GrapesJS 0.23 emits CSS rules (never inline), so export merges the
    generated sheet back into `style` attributes via DOMParser + `matches()` + tiny specificity
    score; `:hover`/`::before` and at-rules are re-emitted in a `<style>` block.
- `EmailTemplateDesignerPage.tsx`: mode Segmented (Visual | HTML | Plain text, visual default);
  visual mode = full-width canvas + token chips + preview in a right Drawer; source modes keep
  the old two-column layout. Editor is `lazy()`-loaded (grapesjs chunk 307kB gzip stays out of
  the main bundle, which shrank to 710kB gzip).
- e2e `email-template.spec.ts`: 3 tests, all green (10.9s). Visual test asserts the saved
  `bodyHtml` contains `{{lastName}}` AND `style="…padding…` inline (email-safe export).
