# 2026-11-09

## System review vs Twenty CRM (research only, no code changed)

- Reviewed backend/frontend/roadmap via codebase exploration + graph query (graphify-out/graph.json, 29,508 nodes) and verified Twenty from official sources (v2.56.1 released 2026-11-05, README 60.7k stars, docs.twenty.com, pricing, package.json).
- Conclusion: CaroCRM wins on out-of-box business breadth (Sales, ServiceDesk, BPM, Voice, ESign, Marketing, CS, Omnichannel), built-in field/record ACL, SQL-first transparency + honest test/gap docs; Twenty wins on production readiness, workspace multi-tenancy, GraphQL/REST/MCP/SDK developer platform, AI/email-calendar sync, 30+ locales, ecosystem and licensing (AGPLv3 + enterprise files).
- Key framing: not apples-to-apples — CaroCRM is a clean-room EspoCRM parity reimplementation, Twenty is a "CRM as code" platform. Biggest architectural split: single JSONB `entity_records` EAV vs physical per-workspace tables (TypeORM).
- Priorities surfaced: P0 license/compliance decision, backup+restore drill and RPO/RTO (G80/G81), PR-gated CI, generated OpenAPI, auth gaps (SSO/OIDC/MFA/password reset), observability; P1 inbound IMAP/Graph mail + calendar sync, API/SDK DX, live-vendor smoke tests; P2 UX polish (optimistic writes, rich text, charts, locales).
- Reference docs for the findings: `docs/quality/phase-22-release-readiness.md` (NO-GO), `docs/quality/known-gaps.md` (G1–G82), `README.md` §"Not built yet", `docs/reference/compatibility-matrix.md`.
