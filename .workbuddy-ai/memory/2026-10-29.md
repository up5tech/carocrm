## Findings worth keeping
- **`vitest.web.config.ts` is `environment: 'node'`, no jsdom, no testing-library.** Component tests must use
  `renderToStaticMarkup` and assert **structure**, not wording: with no catalog loaded, `t()` returns the key, so
  `'Loading'`/`'Retry'` never appear — assert `role`, `aria-live`, the hidden-label class and `<button` instead.
- **antd supplies half the accessibility for free:** `Alert` renders `role="alert"` (so `ErrorState` was already
  fine), `Skeleton` renders **no** role or live region at all. Don't assume, and don't re-add what antd emits.
- **Two loopholes in the conventions gate:** it banned hex literals outside `tokens.css` but not `rgba(...)`, and it
  banned `.slice(0, 19)` but not `new Date(x).toLocaleString()` — which is why 13 screens still printed host-zone
  times behind a comment claiming they didn't. Extend the gate *and* add a `--self-test` case, or the rule regresses.
- **`message.success` auditing:** grep every site and read the 12 lines above it; nearly all were `onSuccess`/`.then`
  or sat after an `await`. The one optimistic cache write (`WebhooksTab` toggle) already restores the previous cache
  on failure. That scan is the honest way to answer §14's "no success before the server confirms".
- **Checked and NOT defects** (do not "fix"): `ESignatureRecordActions` `staleTime: 30_000` is fine because the
  provider sets `refetchOnWindowFocus: 'always'`; `omnichannel/InboxPanel` handoff does invalidate conversations via
  its own `refresh()`.
- Adding a catalog key: insert textually next to a stable sibling in `i18n/en/web.json` **and** `i18n/vi/web.json`
  and re-`json.load` both; a scripted `json.dump` rewrite churns the whole file.
- A python `re.sub` on `.toLocaleString()` must exclude numbers — match `new Date(...)` / `date.` only, or it
  rewrites `value.toLocaleString()` on counts.
