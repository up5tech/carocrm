## Implemented SPEC §9.6 — acting user in the system prompt

- New `apps/api/src/ai-agents/ai-agent-actor.ts`: `AIAgentActorContext`, `promptSafe()`,
  `actorPromptLines()`, and `systemPrompt()` **moved out of** `ai-agent-runs.service.ts` so the
  prompt is a pure, testable function (no API boot).
- `AIAgentRunService.actorContext(userId)` — two bounded reads (`users`, `users_teams ⟕ teams`),
  once per execution attempt, not per step. Deleted user → `undefined`, prompt omits the block;
  the run still fails on ACL, not on a prompt query.
- `promptSafe()` is the security-relevant part: a display name is user-controlled text that lands
  in the **system** message, so control chars/newlines collapse and length is capped — a hostile
  name can never start a new line, therefore never a new instruction.

  rest of the prompt. Format is contract-tested in `ai-agent-actor.test.ts`.
