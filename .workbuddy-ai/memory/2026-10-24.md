## CRM Chat page — UI redesign (apps/web)

Rebuilt `/crm-chat` from a stack of status cards into a chat workspace. Behaviour, hooks, API calls and
i18n keys are unchanged; only presentation moved.

- `CRMChatPage.tsx` — page head (mark + title + state pill + icon actions), `.carocrm-chat-shell` grid
  (312px rail / transcript), hero empty state with 4 suggestion chips, diagnostics **Drawer** holding
  health + capabilities + features + module (was four cards under the thread). `showHealth` → `detailsOpen`.
- `CRMChatMessageList.tsx` — bubbles (user right/blue, assistant left/white), avatars, citation chips,
  own scroll container, sticks to bottom unless the reader scrolled up; new `conversationKey` prop.
- `CRMChatComposer.tsx` — dock frame (borderless textarea), thinking pill with animated dots replaces
  the progress Alert, footer Cancel dropped (the pill's Stop covers it), new `prefill` prop for
  suggestion chips.
- `CRMChatPromptTemplates.tsx` — inline `Empty` removed (it sat inside the composer toolbar).
- `state/i18n.ts` — added `formatClock()` and `isSameCalendarDay()`; new keys
  `web.crmChat.heroTitle|heroHint|suggestionsTitle|suggestion.*` in en + vi.

### Layout gotchas worth remembering

- Shell height is a magic `calc(100vh - 235px)` = 70 header + 48 content padding + 46 head + 14 gap +
  56 footer. Changing the page head's height breaks it; the subtitle is hidden ≤1280px so the head
  never wraps to a second row (a wrapped head makes the page scroll).
- Column flex containers that can overflow **shrink** fixed-height children (the 56px hero mark
  collapsed to a sliver). `> * { flex: none }` is required.
- Centring an overflowing column clips the first item unreachably; `justify-content: safe center` was
  not honoured in Chromium here — use auto margins on the first/last child instead.
- Short threads are bottom-anchored with a `::before { flex: 1 0 auto }` spacer, not `justify-content:
  flex-end` (which breaks scrolling to the top).

Verified in a real browser at 1440×900, 1280×800, 1100×780, 820×1000 and 390×844: no page scroll,
composer always in view. `tsc`, `eslint apps/web/src` and `vite build` all clean.

Playwright again needs `no_proxy='*' NO_PROXY='*'`, and `networkidle` never fires on this page (the
app polls) — wait for `.carocrm-chat-page` instead.

## Shared conversation workspace + voice inbox redesign (apps/web)

The chat work above was committed (`2b50927`). This turn extracted its layout into a shared kit and
rebuilt `/voice-inbox` on it.

### Class rename (CSS + 3 chat files, behaviour untouched)

- Frame: `carocrm-chat-{page,head,mark,status,shell,rail,main,stage,thread,dock,counter}` →
  `carocrm-workspace-*` (`-page-head`, `-pill`, `-rail-*`, `-toolbar`, `-body`, `-scroll`, `-dock-*`).
- Rail row: `carocrm-chat-thread-{item,avatar,text,name,meta,time}` → `carocrm-rail-*`.
- Messages: `carocrm-chat-{msg,bubble,avatar}` → `carocrm-convo-*` (so the inbox reuses the bubbles).
- Chat-only classes kept: `carocrm-chat-{hero,suggestion,thinking,dots,cites,panel,fact,load-older}`.

### Voice inbox (`VoiceInboxPage.tsx`, same file, rewritten in place)

- Page head (mark, title, subtitle, unread pill) + `Segmented` (Conversations | Calls) + reload.
- `InboxRail` / `CallsRail` are `<aside>`s; `ConversationPane` / `CallPane` are `<section>`s — the page
  owns only `surface`/`status`/`channel`/`mine`/`selectedId`/`openCallId`.
- Inbox rail: channel-tinted avatar (`--sms/--whatsapp/--mms/--voice`), tags row, unread badge, stamp.
- Timeline: `carocrm-convo-msg--{inbound,outbound,note}` (note = dashed amber bubble), events as
  `carocrm-inbox-event` with hairline rules; composer is the shared dock frame and turns amber in note
  mode (`.carocrm-workspace-dock-frame--note`).
- Calls: the log moved into the same rail; the call query is `enabled: surface === 'calls'` so it stops
  polling while the inbox is on screen.
- New i18n: `voice.inbox.{subtitle,unread,composerHint}` in en + vi.

### Layout gotchas added to the list

- A toolbar whose actions must stay on the title's row needs `flex: 1 1 0` on the title block, not
  `1 1 auto` — a content-sized basis exceeds the line and wraps the actions instead of shrinking.
- One long tag (a raw UUID in `Case <id>`) pushes a header to a third line: cap `.ant-tag` width.
- With the dock hint hidden on phones, `justify-content: space-between` leaves the Send button at the
  start — switch the foot to `flex-end` in the same media query.

Verified at 1440×900 and 390×844 (inbox, calls, note mode, empty filter, chat page re-checked after
the rename). `tsc`, `eslint apps/web/src`, `vite build` clean. Still uncommitted.
