## CRM Chat page — UI redesign (apps/web)

Rebuilt `/crm-chat` from a stack of status cards into a chat workspace. Behaviour, hooks, API calls and
i18n keys are unchanged; only presentation moved.

- `CRMChatPage.tsx` — page head (mark + title + state pill + icon actions), `.carocrm-chat-shell` grid
  (312px rail / transcript), hero empty state with 4 suggestion chips, diagnostics **Drawer** holding
  health + capabilities + features + module (was four cards under the thread). `showHealth` → `detailsOpen`.
- `CRMChatMessageList.tsx` — bubbles (user right/blue, assistant left/white), avatars, citation chips,
  own scroll container, sticks to bottom unless the reader scrolled up; new `conversationKey` prop.
- `CRMChatComposer.tsx` — dock frame (borderless textarea), thinking pill with animated dots replaces
  the progress Alert, footer Cancel dropped (the pill's Stop covers it), new `prefill` prop for
  suggestion chips.
- `CRMChatPromptTemplates.tsx` — inline `Empty` removed (it sat inside the composer toolbar).
- `state/i18n.ts` — added `formatClock()` and `isSameCalendarDay()`; new keys
  `web.crmChat.heroTitle|heroHint|suggestionsTitle|suggestion.*` in en + vi.

### Layout gotchas worth remembering

- Shell height is a magic `calc(100vh - 235px)` = 70 header + 48 content padding + 46 head + 14 gap +
  56 footer. Changing the page head's height breaks it; the subtitle is hidden ≤1280px so the head
  never wraps to a second row (a wrapped head makes the page scroll).
- Column flex containers that can overflow **shrink** fixed-height children (the 56px hero mark
  collapsed to a sliver). `> * { flex: none }` is required.
- Centring an overflowing column clips the first item unreachably; `justify-content: safe center` was
  not honoured in Chromium here — use auto margins on the first/last child instead.
- Short threads are bottom-anchored with a `::before { flex: 1 0 auto }` spacer, not `justify-content:
  flex-end` (which breaks scrolling to the top).

Verified in a real browser at 1440×900, 1280×800, 1100×780, 820×1000 and 390×844: no page scroll,
composer always in view. `tsc`, `eslint apps/web/src` and `vite build` all clean.
